# Amazon

A responsive Amazon-inspired frontend built using HTML and CSS.

## Features

- Amazon-style navigation bar
- Search bar
- Navigation menu
- Product/category sections
- Hero/banner section
- Shopping cart section
- Responsive layout
- Custom CSS styling

## Technologies Used

- HTML5
- CSS3
